# Rift Squads

A turn-based artillery battle game by Rifted Games.

**Play:** https://riftedgames101.github.io/rift-squads/

**Install on your phone**
- iPhone: open the link in Safari, tap Share, then **Add to Home Screen**.
- Android: open the link in Chrome, tap the menu, then **Install app**.

Also on itch.io: https://rifted-games-101.itch.io
